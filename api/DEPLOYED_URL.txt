口径说明（这些是边界，不是缺陷）
  * A1 brief 解析：部署环境未配置模型凭据，所以线上走确定性规则解析。
    响应里 brief.parse_path=rule，brief.notes 会写明原因；配上凭据即自动切模型路径，
    调用失败/超时也只降级、不让接口报错。
  * A4 语义适配：正式链路用 rule_fit_score（原因见 docs/05-boundaries.md §3.2），与 CLI 一致。
  * 业务错误（brief 空/超长、id 不存在、超批量上限）一律 HTTP 200 + ok:false，
    只有真正的崩溃才 5xx —— 前端据此区分「输入有问题」与「服务挂了」。
  * 服务只读数据，不写任何东西；data/ 是固定种子的合成数据集，没有真实达人信息。
